Side-Trip-Explorer プライバシーポリシー

最終更新日: 2026年10月25日

Side-Trip-Explorer（以下「当方」）が提供するスマートフォン向けアプリケーション（以下「当アプリ」）は、利用者のプライバシーを尊重し、個人情報の保護に努めます。

本ページは、当方のすべてのアプリに共通する方針です。各アプリが保存する情報、権限、通信する外部サービス、広告などの具体的な取り扱いは、アプリと OS ごとのプライバシーポリシーに記載します。

1. 収集する情報について

当アプリは、利用者を識別しうる個人情報（氏名、メールアドレス、電話番号、位置情報など）を無断で収集することはありません。アクセス解析やクラッシュレポートによる利用者の行動追跡も原則として行いません。ただし、アプリの機能のために外部のサービスと通信する場合があります（「5. アプリの機能のための外部サービスとの通信」）。

2. 端末内に保存される情報と権限について

当アプリの各種機能（カメラの使用、写真の読み込み、カレンダーの取得など）を提供するため、端末の機能やデータへのアクセスをお願いする場合があります。これらのデータはすべて利用者の端末内（ローカル環境）でのみ処理・保存され、当方や第三者のサーバーへ外部送信されることはありません（「4. 広告と第三者の SDK について」と「5. アプリの機能のための外部サービスとの通信」に記載したものを除きます）。

3. バックアップについて

アプリ内にデータのバックアップ機能がある場合、書き出されたファイルは利用者が指定した保存先（端末内または任意のクラウド等）に保存されます。当方が特定の保存先へ自動的に送信することはありません。

4. 広告と第三者の SDK について

アプリによっては、広告の表示などのために第三者の SDK を使い、その SDK が端末の識別子などの情報を第三者に送信する場合があります。使う SDK、送信される情報、利用者が設定を変える方法は、OS によって異なるため、アプリと OS ごとのプライバシーポリシーと、各ストアの申告（Google Play のデータセーフティ、App Store のプライバシー情報）に記載します。

5. アプリの機能のための外部サービスとの通信

アプリによっては、機能の提供のために外部のサービスと通信します。通信先と送る内容は、アプリごとのプライバシーポリシーに記載します。

各サービスによる情報の取り扱いは、それぞれのサービスのプライバシーポリシーに従います。当方は、これらの通信の内容を受け取りません。

6. 第三者への提供

当方は利用者情報を外部サーバー等で収集していないため、当方から第三者に提供する情報がありません。「4. 広告と第三者の SDK について」と「5. アプリの機能のための外部サービスとの通信」に記載した、各サービスへの送信は、アプリが利用者の端末から直接行います。法令に基づく開示請求があった場合でも、開示できる利用者の情報を保有していません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、冒頭の最終更新日を改めます。重要な変更がある場合は、アプリのアップデート時等にお知らせします。
