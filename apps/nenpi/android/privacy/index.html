燃費記録（Android）プライバシーポリシー

最終更新日: 2026年10月26日

Side-Trip-Explorer（以下「当方」）は、Android 向けアプリ「燃費記録」（以下「本アプリ」）における利用者の情報の取り扱いを、次のとおり定めます。

1. 当方が収集する情報

当方は、本アプリの利用者の情報を、当方のサーバー等で収集しません。本アプリにはアカウント登録やログインの機能はありません。

2. 端末内に保存する情報

  • 登録した車両、給油記録（給油日時、オドメーター値、給油量、単価、金額、油種、ブランド、店舗名、住所）、設定を、端末内のアプリ専用の領域に保存します。これらは外部に送信しません。
  • 給油記録に付けたレシートの画像を、端末内のアプリ専用の領域に保存します。画像は外部に送信しません。
  • レシートからの文字の読み取り（本アプリに組み込んだ Google の ML Kit）と、給油量や金額などの抽出は、端末内で行います。
  • これらのデータは、Google のバックアップなど、Android による端末のバックアップに含まれる場合があります。
  • 「設定」の「書き出す」を選ぶと、すべての車両と給油記録（レシートの画像は含みません）を1つのファイルに書き出し、利用者が選んだ保存先や共有先に渡します。本アプリがこのファイルを自動で外部に送ることはありません。

3. 権限

  • カメラ：レシートを撮影するために使います。
  • 写真（ストレージ）：レシートの写真を選ぶために使います。Android 12 以前の端末では、写真を読み込むためにストレージへのアクセスを求めます。
  • 広告 ID：「5. 広告」に記載した広告のために使います。

4. 外部サービスとの通信

  • 文字の読み取りに使う Google の ML Kit は、読み取るレシートの画像や文字を送信しません。ただし、機能の性能や利用状況についての情報を Google に送ることがあります。
  • 上記と「5. 広告」に記載した広告の表示を除き、外部サービスとは通信しません。給油記録とレシートの画像・内容は送信しません。
  • 「設定」の「ご意見・ご要望・不具合報告」を選ぶと、端末のメールアプリで当方宛てのメールを作成します。送信するかどうかは利用者が決めます。

5. 広告

  • 画面の上部に Google AdMob の広告を表示します。そのため Google Mobile Ads SDK が、端末の識別子（広告 ID を含みます）、IPアドレス（おおよその地域の推定に使われます）、広告の表示やタップなどの操作の記録、不具合の診断のための情報を収集し、Google に送信します。これらは広告の配信、広告の効果の測定、不正の防止のために使われます。
  • 広告 ID は、Android の「設定」から削除またはリセットできます（表記は端末により異なります。例：「設定」→「プライバシー」→「広告」）。
  • 同意が必要な地域では、広告の表示の前に同意を確認します。同意の内容は、本アプリの「設定」の「広告の同意を変更」から変更できます。
  • Google による情報の取り扱いは、Google のプライバシーポリシーに従います。

6. 第三者への提供

当方は利用者の情報を保有していないため、当方から第三者に提供する情報はありません。「4. 外部サービスとの通信」と「5. 広告」に記載した送信は、本アプリが利用者の端末から Google へ直接行います。

7. 保存期間と削除

  • 給油記録を削除すると、その記録のレシートの画像も端末から削除されます。レシートを撮り直すと、前の画像は削除されます。
  • 車両を削除すると、その車両の給油記録とレシートの画像が削除されます。
  • 「設定」の「すべてのデータを削除する」を選ぶと、すべての車両、給油記録、設定、レシートの画像が削除されます。
  • 「設定」の「読み込む」でバックアップのファイルを読み込むと、端末内のデータはファイルの内容に置き換えられ、それまでのレシートの画像は削除されます。
  • 端末内に保存したデータは、本アプリを端末から削除すると、すべて削除されます。端末のバックアップに含まれたデータと、書き出したファイルは、それぞれの保存先の扱いに従います。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、冒頭の最終更新日を改めます。
